MasterForge is a browser-based, professional-grade Audio Mastering Toolkit, fully equipped with state-of-the-art neural algorithms, multi-stage transient shaping, SSL-style glue compression, and dynamic mid/side equalizers.

## Features

- **Pristine Quality**: 32-bit floating point processing & 8x oversampling.
- **Smart Profiles**: Optimized targets for Spotify, YouTube, and TikTok.
- **Local First**: All DSP happens directly in your browser. No files are uploaded to any server.
- **AI Audio Restoration**: Built-in de-harshing and saturation for neural-generated audio (e.g. Suno/Udio artifact reduction).
- **Comprehensive Visuals**: Dynamic M/S EQ visualizers.
- **Accessibility & i18n**: Fully accessible UI with light/dark theme support and English/French localizations.
